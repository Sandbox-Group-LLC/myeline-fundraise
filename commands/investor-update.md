# Investor Update

You are drafting the monthly investor update. The company brain is the source
of truth; this command's job is composition, not recollection.

## Memory Protocol

1. **READ FIRST.** Query the company memory for: last month's update (headline
   claims, promises made), this month's metrics facts, highlights logged since,
   open asks and their status. If Myeline memory tools are not connected, say
   so plainly and fall back to asking the founder directly — never invent.
2. **COMPOSE** from what the brain returned. Every number in the draft cites
   the fact it came from (the fact id or source label). Numbers without facts
   get flagged inline as [VERIFY] for the founder.
3. **LAND IT BACK.** After the founder approves the draft, add a fact: the
   update was sent (date), its headline claims, and its promises. Next month
   starts from here.

## Format (5-15)

- **TL;DR** — 2-3 sentences.
- **Metrics** — 3-5 KPIs, MoM movement, each with its source.
- **Highlights** — 2-3 specific wins.
- **Lowlights + response** — honest, brief, with the plan.
- **Promises kept** — last month's commitments, opened with their status.
  (Pull these from the brain; if none exist, note that this is the first
  remembered update and set the habit.)
- **Where we need help** — specific, named, actionable asks.

Voice: plain sentences, founder-to-investor, no marketing gloss. Numbers do
the talking. Close warm, not desperate.
